v2.3.2
ANFMise à jour du launcher07/11/2026

Si t'as déjà le launcher, rien à faire : il se met à jour au prochain lancement.

v2.3.2 :

  • Occlusion plus fondue : moins de traits noirs fins sur les arêtes, et un réglage Douceur pour les faire disparaître.

v2.3.1 :

  • Occlusion refaite : une échelle pour les recoins, une pour les détails fins (visages, plis). Plus douce sous les persos, elle n'ajoute plus de noir sur les ombres du jeu.
  • Six réglages dans la page Rendu, et le FOV du jeu est pris en compte.

v2.3.0, l'occlusion ambiante :

  • Le rendu ANF ombre les recoins, le pied des murs, le contact entre les persos et le sol. Activé de base, sur le serveur aussi, et gardé quand tu changes de style.
  • Pour ça le launcher passe à la version « add-on » de ReShade, la seule qui laisse voir la profondeur en ligne. Son auteur la conseille plutôt pour les jeux solo : si ça te gêne, le bouton Retirer de la page Rendu enlève tout.
  • Ça coûte quelques FPS. Si ton PC galère, baisse l'occlusion à zéro dans la page Rendu.

v2.2.2 :

  • Nouveau style Réalisme dans la page Rendu.
  • Bouton « Importer un preset » : quelqu'un te passe son ANF.ini, tu le choisis, c'est appliqué.

v2.2.1 :

  • Moins de lag avec le rendu ANF : ReShade ne cherche plus la profondeur de l'image, ce qui lui faisait suivre chaque objet dessiné.
  • Le rendu se règle en jeu : touche Début, panneau aux couleurs d'ANF, en français. Le launcher reprend ces réglages quand tu reviens dessus.
  • Couper le rendu passe sur la touche Fin. F10 ouvrait la console chez certains.

v2.2.0, le rendu ANF :

  • Le Rendu passe par un shader fait pour ANF, chargé avec ReShade. Il marche sur le serveur, ce que les effets de GMod ne faisaient pas (le serveur les bloque).
  • Un bouton Installer dans la page Rendu, un bouton Retirer. Le launcher récupère ReShade tout seul et ne touche à rien d'autre.
  • Halo sur six niveaux, virage ombres / hautes lumières, blancs doux, grain, vignettage, netteté sans liseré.
  • L'aperçu du launcher tourne avec le même code qu'en jeu. Ce que tu vois, c'est ce que t'auras.
  • En jeu : Début pour ouvrir ReShade, F10 pour couper le rendu et comparer.

Avant :

  • v2.1.5 : profils de perf nettoyés (que des réglages reconnus par GMod), plus de spam « cheat cvar » dans la console.
  • v2.1.4 : les effets du Rendu s'affichent de nouveau en jeu.
  • v2.1.2 : cache des modèles au maximum dans les profils de perf.

v2.1.0 :

  • Nouvelle interface, même DA que le menu du jeu.
  • Choix du serveur avec les cartes en bas à droite. SNK ouvert, WW2 arrive.
  • Le jeu se lance direct en 64 bits (Chromium). Plus de fenêtre Steam pour choisir, plus de « Rejoindre ? ».
  • Un mot de passe enregistré par serveur.
  • Bouton pour remettre le menu d'origine de GMod si tu veux, sans vérifier les fichiers du jeu.
  • Le menu en jeu passe à la nouvelle DA.
